# template: the smallest working face

`index.html` loads `app.css` and the module `app.js`, which imports `kit.js`. The page asks
for a ledger and an item number, reads the item's JSON face, and shows its title, state and
labels. Copy the directory, rename it, and replace `show` in `app.js` with your question.
See `../README.md` for the config line, the CSP rules and how to check it in a browser.
